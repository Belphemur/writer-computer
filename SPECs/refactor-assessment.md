# Refactor assessment: DRY > SOLID > KISS

Read-only audit of `apps/desktop/src` (TypeScript) and `apps/desktop/src-tauri/src` (Rust). Baseline: the working tree on 2026-11-17 (HEAD `69dbe87` plus roughly 128 modified and 50 untracked files from agents working concurrently). Anything touching the agent pane composer/model picker, code files or the sign-in probe is marked **in flux**: re-check line anchors before starting. Line numbers are as read.

Method and tools actually run:

- `jscpd@4` (via `npx`, nothing installed in the repo): textual clones. TS 74 clones / 0.95% duplicated lines (min 5 lines, 40 tokens); Rust 12 clones / 0.32%. Textual duplication is low. The real debt is duplicated knowledge with different spelling, found with `rg` and by reading.
- `knip@5` with a scratchpad config (entries `src/main.tsx` + `tests/**`): 1 unused file, 95 unused value exports, 124 unused type exports (most are over-exported or test-only; the worthwhile ones are listed below).
- `cargo clippy --all-targets --offline` into a scratchpad target dir: 10 lib warnings, 16 with tests, almost all style. Dead code: `commands/fs.rs:894 delete_entry_impl` never used; `index/names.rs:858` field `vault` never read (test).
- `rg` for twin functions, repeated literals and branch chains. Command reachability: 126 `#[tauri::command]` fns, 10 never referenced from `src/`, `tests/` or `e2e/` (list in K1).

## 1. Verdict

The codebase is in better shape than the line counts suggest: Rust cores are Tauri-free with traits (`ProjectPort`, `ChatPort`, `SecretBackend`, `Consent`, `Clock`, `RowSource`), TS `invoke` is confined to `lib/*client*.ts` wrappers (three components call only `convertFileSrc`), settings, page kinds, palette commands and Bases views are registries, and the big cross-language twins are pinned by shared data (`shared/*.json`, goldens, vectors). The problems are concentrated in four places:

1. **UI shells re-copied** (popover dismiss, chip menus, modal backdrop, native context menu builder, Tailwind button/row strings, icon button, dock pane resize). A hook for the popover dismiss was even written and then never imported.
2. **Small mechanisms re-implemented per file** in both languages (error-message extraction, path helpers, frontmatter splitting, "is this a note" extension checks, atomic write, timeout-kill process loop, `now_ms`, bounded vault walker, latest-wins sequencing, debounced serial save).
3. **Enumerations hand-listed in 3 to 5 places** (permission modes, effort levels, enabled-model defaults, pane width range, agent folder roots, event names).
4. **God stores** (`editor-store.ts` 1626 lines with 79 actions, `agent-store.ts` 846, `plugins-store.ts` 802) and `commands/fs.rs` (1571 lines, 5 concerns) which are where each new feature lands.

No finding below reverses an accepted ADR. Two ADR-adjacent items are called out in section 9 (a second hidden-folder rule contradicts the 2026-11-17 visibility ADR's "patterns to avoid"; adopting generated IPC types needs a new ADR).
